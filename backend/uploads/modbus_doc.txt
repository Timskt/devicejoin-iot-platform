Modbus 工业设备点位与数据字典说明

一、通信参数

• 协议类型：Modbus RTU / TCP  
• 从站地址（Slave ID）：1  
• 波特率：9600 bps  
• 数据位 / 校验 / 停止位：8 / N / 1  
• 寄存器规则：16 位整型，大端序（Big Endian）

二、Modbus 点位表（示例）

点位名称 寄存器地址 寄存器类型 数据类型 读写权限 描述

设备运行状态 40001 Holding Register UInt16 只读 设备当前运行状态

故障代码 40002 Holding Register UInt16 只读 当前故障编号

设定运行频率 40003 Holding Register UInt16 读写 设备目标运行频率

实际运行频率 40004 Holding Register UInt16 只读 实时反馈频率

输出电压 40005 Holding Register UInt16 只读 单位：0.1 V

输出电流 40006 Holding Register UInt16 只读 单位：0.1 A

启停控制 00001 Coil Bool 读写 启动/停止设备

复位命令 00002 Coil Bool 读写 故障复位

三、命令本（功能码说明）

功能码 名称 用途说明

01 Read Coils 读取线圈状态（启停、复位等）

02 Read Discrete Inputs 读取离散输入状态

03 Read Holding Registers 读取保持寄存器（运行参数、设定值）

04 Read Input Registers 读取只读输入寄存器

05 Write Single Coil 写入单个线圈（启停控制）

06 Write Single Register 写入单个保持寄存器

16 (0x10) Write Multiple Registers 批量写入多个寄存器

四、数值范围与换算规则

1. 运行状态（40001）
数值 含义
0 停机
1 运行
2 故障
3 待机

2. 设定运行频率（40003）
• 取值范围：0 – 5000  
• 换算公式：实际频率(Hz) = 寄存器值 ÷ 100  
• 示例：2000 → 20.00 Hz

3. 输出电压（40005）
• 取值范围：0 – 4000  
• 单位：0.1 V  
• 示例：3800 → 380.0 V

4. 输出电流（40006）
• 取值范围：0 – 2500  
• 单位：0.1 A  
• 示例：1250 → 125.0 A

5. 启停控制（00001）
• 0：停止  
• 1：启动  

五、异常码说明（简要）

异常码 含义
01 非法功能
02 非法数据地址
03 非法数据值
04 从站设备故障
