# 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品定位
DeviceJoin 是一个 **AI 驱动的 IoT 平台**，核心目标是让非技术人员也能独立完成设备接入、配置、运维全流程，彻底摆脱对开发人员的依赖。

### 1.2 目标用户
- **设备运维人员**: 不需要懂编程，通过自然语言操作
- **项目实施工程师**: 快速部署设备，自动生成配置
- **产品经理**: 一句话创建监控面板、告警规则

### 1.3 核心痛点

| 痛点 | 现状 | 解决 |
|------|------|------|
| 设备接入慢 | 开发人员逐页分析协议文档，手动配置点位 | AI 自动解析文档，30秒生成配置 |
| 看不懂日志 | 设备异常时只能找开发看报文 | AI 自动诊断并给出中文修复建议 |
| 配置门槛高 | 写告警规则要懂 SQL/表达式 | 自然语言描述即生成规则 |
| 查数据麻烦 | 要看数据得找开发写查询 | 自然语言查询，AI 翻译+可视化 |
| 面板建设慢 | 每个项目都要开发定制大屏 | AI 自动布局，3秒出大屏 |
| 测试等硬件 | 没硬件就无法开始联调 | AI 模拟器生成逼真虚拟设备 |

## 2. 功能模块

### 2.1 AI Product Studio (产品智能工坊)

**功能描述**: 上传设备技术文档（任意格式），AI 自动提取产品配置。

**输入**:
- 设备协议手册 (PDF, Word, Markdown)
- 寄存器映射表 (Excel, CSV)
- 点位说明截图 (PNG, JPG)
- 任意补充文本 (自然语言)

**处理流程**:
```
文档上传 → 格式解析 → 概览分析 → 精细提取 → 推断补全 → 人工审核
```

**AI 能力**:
1. 自动识别通信协议 (Modbus RTU/TCP, MQTT, BACnet, HTTP, 私有串口)
2. 提取数据点位 (名称、寄存器地址、数据类型、单位、量程)
3. 提取命令定义 (命令名、参数、响应格式)
4. 推断缺失信息 (量程、单位、数据类型)
5. 关联命令与点位
6. 置信度标注 (高/中/低)，不确定的提示用户确认

**输出**:
- 结构化的产品配置 (Products + DataPoints + Commands)
- 置信度报告
- 不确定项清单 (可点击追问AI)

### 2.2 AI Debug Assistant (智能调试助手)

**功能描述**: 设备连接异常时，AI 自动分析日志和报文，给出诊断结果和修复建议。

**输入**:
- 设备信息 (型号、协议、连接参数)
- 原始日志/报文
- 异常现象描述 (自然语言)

**AI 能力**:
1. 解析 Modbus/MQTT 原始报文
2. 匹配常见故障模式 (超时、CRC错误、地址冲突...)
3. 逐步引导排查 (先检查哪 → 再检查哪)
4. 历史问题知识库匹配

**输出**:
- 诊断结论
- 可能原因列表 (按概率排序)
- 分步修复建议
- 需要的补充信息

### 2.3 AI Rule Composer (智能规则编排)

**功能描述**: 自然语言描述 → 结构化告警/联动规则。

**示例**:
| 用户输入 | AI 输出 |
|---------|--------|
| "温度超过80度持续5分钟就发短信" | alert: temperature > 80, duration=300s, action=sms |
| "每天早上8点读取所有电表" | automation: cron(0 8 * * *), action=read_all_meters |
| "湿度低于20%自动打开加湿器" | automation: humidity < 20, action=turn_on_humidifier |

**AI 能力**:
1. 匹配自然语言中的触发条件
2. 识别持续时间和防抖需求
3. 推断告警通道和联动设备
4. 告警风暴风险评估

### 2.4 AI Data Explorer (智能数据探索)

**功能描述**: 自然语言查询设备历史数据，AI 自动选图展示。

**示例**:
| 用户输入 | AI 处理 |
|---------|--------|
| "今天温度最高的设备" | 查询 → 排序 → 表格+排行 |
| "过去7天用电趋势" | 聚合 → 折线图 |
| "各车间能耗对比" | 分组 → 柱状图 |
| "A相电压突变的设备" | 异常检测 → 标注图 |

### 2.5 AI Dashboard Builder (智能面板构建)

**功能描述**: 一句话生成监控大屏，自动布局。

**示例**:
- "工厂1号车间的环境监控大屏" → 温度仪表盘 + 湿度仪表盘 + 趋势图
- "电能质量监测" → 三相电压表 + 电流表 + 功率因数

**AI 能力**:
1. 按语义分组点位 (温度放一起，电能放一起)
2. 自动选择组件类型 (仪表盘/折线图/表格)
3. 自动设置量程和告警线
4. 支持模板复用

### 2.6 AI Simulator (智能模拟器)

**功能描述**: 硬件未到时，AI 生成虚拟设备进行联调测试。

**AI 能力**:
1. 根据产品配置自动生成符合真实规律的模拟数据
2. 支持多种数据模式 (稳定/增长/周期波动)
3. 注入异常场景 (传感器故障、通信中断)
4. 支持批量模拟 (1000+ 设备并发测试)

### 2.7 AI Protocol Studio (智能协议适配)

**功能描述**: 上传私有协议文档，AI 生成解析代码。

**支持协议**:
- Modbus RTU/TCP (标准)
- MQTT (自定义Topic/Payload)
- 串口自定义协议 (帧头 + 数据 + CRC)
- HTTP API

## 3. 非功能需求

### 性能指标
- AI 文档解析: ≤ 30秒 (100页以内)
- 数据查询: ≤ 2秒
- 并发设备连接: ≥ 10000

### 安全需求
- 设备密钥加密存储
- API 访问 JWT 认证
- 数据脱敏 (日志中的密钥/密码)

### 可扩展性
- 支持多 LLM 提供商 (OpenAI / DeepSeek / Ollama / 本地模型)
- 插件化的协议适配
- 点位知识库持续学习
