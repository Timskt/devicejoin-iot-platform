# 用户使用指南

## 零基础接入设备：从文档到产品只需 3 步

### 场景: 你拿到了一台全新的温湿度传感器，只有一份 PDF 协议手册

---

## Step 1: 上传文档

打开产品管理页面 → 点击「智能接入」→ 拖入所有相关文档:

```
✓ 温湿度传感器协议手册V2.3.pdf
✓ 寄存器映射表.xlsx
✓ 接线示意图.png (可选)
```

**支持格式**: PDF, Word, Excel, Markdown, TXT, PNG, JPG

**技巧**:
- 可以一次上传多个文件，AI 会自动合并分析
- 文档越全，AI 解析越准确
- 图片中的表格也会被 OCR 识别

---

## Step 2: AI 自动解析 (30秒)

点击「开始分析」→ AI 开始工作:

```
进度:
[✓] 解析 PDF 文本...完成
[✓] 提取表格数据...完成
[✓] 识别通信协议: Modbus RTU
[✓] 提取数据点位: 6个
[✓] 提取命令: 2个
[✓] 推断补全缺失信息
[✓] 分析完成，置信度: 85%
```

**置信度颜色说明**:

**点击「问AI」**可以针对不确定项追问:
```
你: 告警状态为什么要推断为uint16？
AI: 根据文档第5页描述"告警寄存器 Bit0=高温 Bit1=高湿"，
    这是一个位标志寄存器，用uint16存储最合适。
```

---

## Step 3: 确认并创建

确认无误后，点击「确认并创建产品」→ 产品配置自动入库，设备立即可用。

## 更多 AI 功能

### 🔍 设备调试

设备连不上？复制日志到调试面板：

```
你: [粘贴 Modbus 通信日志]
    Modbus Read Error: Timeout on register 40001
    CRC Check Failed on response frame 01 03 04 00 00...

AI: 诊断结果：
    1. CRC校验失败 → 可能485总线有干扰，检查终端电阻
    2. 读取超时 → 可能是波特率不匹配
    → 建议：先降到9600波特率测试，正常后逐步提升
```

## 配置 AI 模型

支持多种 AI 模型提供商，编辑 `.env` 文件:

```bash
# 使用 OpenAI
LLM_API_KEY=sk-xxx
LLM_API_BASE=https://api.openai.com/v1
LLM_MODEL=gpt-4o

# 使用 DeepSeek (更便宜)
LLM_API_KEY=sk-xxx
LLM_API_BASE=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat

# 使用本地 Ollama (免费，需本地部署)
LLM_API_KEY=ollama
LLM_API_BASE=http://localhost:11434/v1
LLM_MODEL=qwen2.5:14b
```
